## 🚀 Projetos em destaque

### 📊 Impacto do Turismo nas Cidades

Participei do desenvolvimento de um painel interativo que reúne **76 indicadores sociais, econômicos e ambientais de oito municípios do Nordeste**. Os filtros e gráficos permitem comparar os municípios e explorar como os impactos do turismo variam de um território para outro.

O projeto foi desenvolvido em equipe no **Capacita Brasil C-Jovem**, em parceria com a **Embrapa** e o **BID**.

🐍 **Tecnologias:** Python, Pandas, Streamlit e Plotly.

### 🔗 Aprendizagem Federada com gRPC

Como treinar um modelo em conjunto quando os dados estão distribuídos entre vários clientes? Neste trabalho de **Sistemas Distribuídos**, cada cliente treina o modelo localmente com dados do conjunto Iris. Um servidor recebe os parâmetros por **gRPC** e os combina com o algoritmo **Federated Averaging (FedAvg)**.

Uma interface web permite acompanhar as rodadas de treinamento em tempo real. Os clientes e o servidor usam **Protocol Buffers** para representar os parâmetros trocados.

⚙️ **Tecnologias:** Python, gRPC, Protocol Buffers, scikit-learn, FastAPI e Server-Sent Events (SSE).

[![Ver projeto](https://img.shields.io/badge/Ver_projeto-181717?style=for-the-badge&logo=github&logoColor=white)](https://github.com/felpsrib/aprendizagem-federada-grpc)

### 🎒 Simulador da Mochila 0/1

Quais itens levar para obter o maior valor possível sem ultrapassar um limite de peso? Neste trabalho da disciplina de **Projeto e Análise de Algoritmos**, o usuário pode alterar os itens e a capacidade da mochila e observar como essas escolhas afetam a solução.

O simulador funciona no **navegador e no terminal**. Na versão web, a tabela de **programação dinâmica** destaca o caminho que explica por que cada item entrou ou ficou de fora.

🐍 **Tecnologias:** Python, HTML, CSS e JavaScript.

[![Ver projeto](https://img.shields.io/badge/Ver_projeto-181717?style=for-the-badge&logo=github&logoColor=white)](https://github.com/felpsrib/mochila-01-python)
