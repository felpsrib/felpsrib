Participei do desenvolvimento de um painel interativo que permite comparar **76 indicadores sociais, econômicos e ambientais em oito municípios do Nordeste**. O projeto foi desenvolvido em equipe no Capacita Brasil C-Jovem, em parceria com a Embrapa e o BID.

Projeto de Sistemas Distribuídos que explora como clientes e servidor cooperam no treinamento de um modelo. A comunicação usa **gRPC e Protocol Buffers** para transmitir os parâmetros do modelo entre os participantes.

**Tecnologias:** Python, gRPC e Protocol Buffers.

### 🎒 Simulador da Mochila 0/1

Simulador desenvolvido para a disciplina de Projeto e Análise de Algoritmos. O usuário altera os itens e o limite de peso e acompanha, na tabela de programação dinâmica, como o algoritmo encontra a combinação de maior valor. O projeto pode ser executado no navegador ou no terminal.

**Tecnologias:** Python, HTML, CSS e JavaScript.  
[Ver código e exemplo de execução](https://github.com/felpsrib/mochila-01-python)
